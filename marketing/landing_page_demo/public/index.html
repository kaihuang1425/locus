Questions, answered

The important things before you install.

Is Locus free to use?＋

Locus is designed to have a useful free tier. Premium features can later cover advanced automation, cloud sync, AI organization, additional plugins, and themes.

What data does the extension access?＋

Only the permissions needed for features you choose to use. The final store listing should explain every permission in plain language and link to a detailed privacy policy.

Can I import and export my library?＋

Yes. Import and export should be first-class features so your saved resources are never trapped inside Locus.

Does it replace my browser’s new tab?＋

It can provide a Locus new-tab experience while preserving familiar search and shortcut access. The exact behavior should remain configurable.

Will sync work across devices?＋

Local use can remain available, while optional cloud sync can be introduced as a premium feature for people who need it.

Which browsers are planned?＋

Chrome-compatible browsers are the natural first target, followed by Firefox and Safari as the product matures.
