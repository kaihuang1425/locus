What it does

Close a tab without losing its place.

Browser work piles up because it is unfinished. Locus turns open tabs into saved references you can organize, find, and reopen deliberately.

Save the mess

Use the toolbar popup to save the current tab or a window after reviewing the destination and close behavior. Right-click capture and Ctrl+Shift+S are also available.

Reopen only what matters

Saved pages can open through a packaged placeholder. The destination loads only after you choose to continue, so a saved reference does not have to remain a live tab.

Find anything later

Search by words, type, color, tag, domain, or todo state, and exclude what you don't want with a minus.

type:tab in:work domain:github.com -is:done

The workspace

One workspace, arranged your way

Tabs are only half of browser work. The other half is what you meant to do with them.

More than tabs

Notes sit beside the pages they refer to. Todos check off. Reminders can be scheduled and projected onto a calendar; overdue, restart, and timezone behavior still require release-candidate validation. Stacks nest inside stacks when a project outgrows a card.

Core and advanced views

Board and list stay in the core path. Canvas, explorer, timeline, gallery, and graph remain available under Advanced when a project needs a different shape.

Privacy

Local workspace, no Locus cloud

Workspace data lives in this browser profile's local extension storage. Export backups are user-managed; uninstalling the extension or deleting the profile removes that local data. Locus has no account, backend, or host permissions. Saved-content search stays inside Locus; opening a destination still connects through your browser.

No Locus account

There is no sign-up flow. Load the extension and open a new tab.

No Locus backend

Workspace data lives in chrome.storage.local in this browser profile; Locus does not operate a backend for it.

No host permissions

Locus has no permission to inspect site content. Explicit capture stores the page, link, selection, or image URL you choose.

Portable data

Export the workspace as JSON and keep the backup yourself. Compatible imports show a preview before touching your data.

Blur for screen shares

One setting blurs the whole board when someone else can see your screen.

Source available

Research, contribution, and informal personal use only. No commercial use in any form.

Evidence gates, not promises

Prove the core before expanding it

Near-term work is limited to outcomes that can be tested. Ideas do not become commitments until they pass the product, reliability, and distribution gates.

Prove save → recover

Measure whether first-time users can save, close, find, and reopen a page without guidance or data loss.

Make recovery boring

Stress-test concurrent writes, imports, exports, reminders, large archives, and rollback paths before calling them dependable.

Finish first-use UX

Validate the single-task welcome, simplify the everyday shell, and close keyboard, contrast, and screen-reader gaps.

Earn distribution

Resolve licensing, naming, store scope, and public claims before asking a broad audience to install the extension.

The gates, owners, measures, and stop conditions live in the Product Success System.

Install

Load the research alpha unpacked

Locus is not on the Chrome Web Store yet. Until it is, it loads as an unpacked extension:

  1. Download or clone the repository from GitHub.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click "Load unpacked" and choose the locus folder.
  4. Open a new tab. That's it.
