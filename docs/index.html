The practical bits

A few things
before you move in.

Can I install it today?+

Yes, as an unpacked extension in Chrome or Edge. Locus is a research alpha, so expect rough edges. It is not currently a browser-store release.

Does it save the contents of every page?+

No. Locus saves references to pages and the notes or content you explicitly capture. It is not an offline archive of the web.

Do I need AI to use it?+

No. Saving, organising and finding your work do not need AI. Planning with an external assistant is optional; you choose what to share and which tasks to keep.

Will it sync across my devices?+

No automatic sync is included. Your workspace belongs to a browser profile; you can export and import backups yourself.

Is the source available?+

Yes. You can inspect the source on GitHub. Locus uses a noncommercial research licence; check the licence before reusing it.

Install the
research alpha

Locus runs as an unpacked desktop extension in Chrome or Edge.

  1. Download the source ZIP and unzip it into a folder you’ll keep.
  2. Open chrome://extensions or edge://extensions, then turn on Developer mode.
  3. Click Load unpacked, select the unzipped folder, and open a new tab.
