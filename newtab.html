    LOCAL DATA BOUNDARY

    What Locus stores and can access

    These limits come from this extension's storage, permissions, and network policy.

    Storage This browser profile

    Workspace data and preferences are stored locally for this browser profile.

    Locus network No backend connection

    Extension pages cannot make network requests. Choosing Open still loads the saved website in a browser tab.

    Browser access Zero host permissions

    Locus can manage tabs, bookmarks, storage, alarms, notifications, and favicons, but cannot automatically inspect page content.

    Recovery Manual JSON backup

    Uninstalling Locus or losing this profile can erase local data. Download a backup first.

    Locus can request the download, but cannot verify that the browser saved the file.
    Screen-share mask plugin Optional local display mask. It changes only what Locus displays. Available

    Mask saved content

    Obscures saved titles and locations in Locus and hides destinations in capture notifications. It does not encrypt, delete, or change saved data.

    The screen-share mask setting is stored in this browser profile.
